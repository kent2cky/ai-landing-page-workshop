# Prompt 2: Refine Your Page

After AI Studio builds your first version, use these follow-up prompts in the **chat box on the left** to improve it.

**Golden rule:** ask for **one or two changes at a time**, then check the preview before asking for more. Big lists of changes in one message are where things break.

---

## Fix the look

```text
Make the design feel more [premium / playful / modern / calm]. Use more white space, larger headings, and softer shadows on the cards.
```

```text
Change the color scheme to [COLORS]. Keep the text easy to read on every background.
```

```text
Use a more elegant font for headings (like Playfair Display) and a clean font for body text (like Inter), loaded from Google Fonts.
```

## Fix the words

```text
Rewrite the hero headline so it's shorter and speaks directly to [YOUR CUSTOMERS]. Give me 3 options in the chat first; don't change the page yet.
```

```text
Change the hero headline to: "[YOUR CHOSEN HEADLINE]"
```

```text
Fix any spelling or grammar mistakes on the page. Use [British / American] English.
```

## Add your own photos

1. Click the **+** (Add files) button in the chat box and upload your photos and logo.
2. Then send:

```text
I've uploaded my logo and photos. Use the logo in the top bar and footer. Replace the gallery placeholders with my uploaded photos, and use the best one as the hero background with a dark overlay so the text stays readable.
```

## Add useful features

```text
Add a "Get directions" button in the location section that opens this Google Maps link: [YOUR MAPS LINK]
```

```text
Add a short FAQ section before the contact section with these questions and answers: [Q1 and A1], [Q2 and A2], [Q3 and A3]
```

```text
Add a favicon using my logo, and set the browser tab title to "[BUSINESS NAME] | [SHORT DESCRIPTION]".
```

```text
Add SEO basics: a meta description that says "[ONE SENTENCE ABOUT YOUR BUSINESS AND LOCATION]" and social sharing tags so the link looks good when shared on WhatsApp.
```

## Fix problems

```text
On mobile, the [SECTION NAME] looks squashed/overlapping. Fix the mobile layout for that section only.
```

```text
The WhatsApp button doesn't open the right chat. Make sure every WhatsApp button links to https://wa.me/[YOUR NUMBER]
```

```text
Undo your last change. I preferred the previous version.
```

## Point at the exact thing (annotation mode)

Not sure how to describe it? Use **annotation mode** in the preview: highlight the part of the page you want changed and type what you want, e.g. "make this button bigger and gold".
